# System Modules – ShadowSlayers – Legends of Elements

## Runtime Boundaries

- **Bot (`apps/bot/src/main.ts`)** owns the sole Discord Gateway connection and persistent scheduler. Its production install uses `npm ci --omit=dev`; compiled output is `dist-bot/`.
- **Dashboard (`src/`)** is a static GitHub Pages SPA built to `dist/`; it has no Discord or Firebase Admin credentials.
- **Trusted API (`server.ts`)** is a separate API-only service built to `dist-api/`. It owns authentication and privileged Firestore access, but does not start a bot or scheduler. Live Discord-dependent dashboard mutations are authorized and signed by the API, then dispatched to the bot through the shared Firestore command queue.
- Firebase client operations: none currently approved. The current schema, Firebase Auth setup, Firestore rules, and session model are not aligned for direct browser access.

1. **Discovery & Setup Engine (`apps/bot/src/services/discovery.ts`, `apps/bot/src/commands/setup.ts`)** — Maps all 9 legacy categories, 32 text channels, 5 voice channels, and 16 legacy roles (`👑 Shadow King` manual-only), flags misplaced channels, type mismatches, permission drifts, and ambiguous conflicts, and runs an ephemeral initiator-locked `/setup` confirmation flow.
2. **Dynamic Multilingual Engine (`packages/localization/src/engine.ts`)** — Supports English (`en`), Russian (`ru`), and unlimited admin-created languages (e.g., Swedish `sv`) via templates, manual translation editing, completeness scoring, review approval, and non-destructive channel generation previews. Creating language categories on Discord requires an active Discord connection (offline returns 503 without mutating state).
3. **5-Step Onboarding & Verification (`apps/bot/src/services/onboarding.ts`)** — Isolates new members in `📜 01 — GATE OF SHADOWS` until `📜・rules` `✅` acceptance grants `✅ Verified`, tracks Language (Step 2), Class (Step 3), optional Notifications (Step 4), and gates `🌱 Recruit` on Step 5 active-player confirmation while preserving unrelated roles on `✅` removal. Unranked members remain `clanRank: null` (never defaulted to `'🌱 Recruit'`). Role grants require an active Discord connection; offline requests return 503 without updating database records.
4. **Role Management** — Replaces Carl-bot with exclusive Language (`🇬🇧 English` / `🇷🇺 Русский`) & Class (`⚔️ Warrior` / `🔮 Sorcerer` / `🗡️ Swordsman`) panels in `🎭・choose-your-role` & `🎭・выбор-ролей`, multi-select Notifications (`📢 Event Pings`, `🐉 Boss Pings`, `🏆 PvP Pings`), leadership-only Clan Rank blocking, temporary roles, and safe `/roles publish`. Publishing panels requires an active Discord Gateway; offline attempts preserve draft state and return 503.
5. **Moderation & Appeals** — Case-numbered actions (`/warn` through `/appeal`), confirmation guards on destructive actions (`ban`/`kick`/`purge`), hierarchy & bot-position enforcement, live Discord execution status (`verified_live` / `failed`), argument validation before side effects, and persistent tempban expiration. Offline requests return 503 without creating active punishments or false success records.
6. **Rule-Based AutoMod & Custom Responses (`apps/bot/src/services/automod.ts`)** — Deterministic spam, repeat-message, mass-mention, phishing/invite link, blocked-word, raid-spike, and new-account filters with false-positive reporting (`/false-positive <message_id> <reason>`), emergency lockdown, and deterministic keyword/prefix custom responses (`/custom-response <action>`).
7. **Centralized Logging** — 17-category searchable audit trail with configurable Discord log channels and retention pruning. High-frequency logs isolate into subcollection `guilds/{guildId}/logs` under Firestore.
8. **Member Progression (`apps/bot/src/services/xp.ts`)** — Anti-farming XP engine with cooldowns, duplicate suppression, levels, achievements, and leaderboards.
9. **Recruitment** — Multi-category configurable forms, submission queue, and reviewer-attributed approve/reject workflow.
10. **Tickets & Support** — Numbered private tickets, claim/transfer/close/reopen, transcripts, and feedback.
11. **Community Suite** — Suggestions, polls, giveaways, events, reminders, birthdays, challenges, inactivity reports, and scheduled announcements.
12. **Clan & Gaming Management** — Game-agnostic classes, teams/squads, raid & dungeon schedules, and attendance tracking.
13. **Persistent Scheduler (`apps/bot/src/services/scheduler.ts`)** — Crash-safe, idempotent background task runner surviving restarts without duplicate dispatch. In Firestore, tasks reside in subcollection `guilds/{guildId}/scheduledTasks` with transaction-protected status reconciliation. It runs only in the standalone bot process.
14. **Production Database Adapter (`packages/database/src/firestore-adapter.ts`)** — Official Firebase Admin SDK adapter with guild-level isolation, subcollections, transactions, per-guild locks, exponential backoff retries, and strict non-fallback behavior.
